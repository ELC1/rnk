RNK custom assets

Coloque aqui os arquivos customizados das skins do servidor.

Estrutura sugerida:
- models/rnk/characters/red/red_agent.mdl
- models/rnk/characters/blue/blue_agent.mdl
- models/rnk/weapons/ak_gold/v_ak47_gold.mdl
- models/rnk/weapons/ak_gold/w_ak47_gold.mdl
- models/rnk/weapons/m4_carbon/v_m4a1_carbon.mdl
- models/rnk/weapons/m4_carbon/w_m4a1_carbon.mdl
- models/rnk/weapons/awp_ice/v_awp_ice.mdl
- models/rnk/weapons/awp_ice/w_awp_ice.mdl
- models/rnk/knives/crimson/v_knife_crimson.mdl
- models/rnk/knives/crimson/w_knife_crimson.mdl
- models/rnk/knives/obsidian/v_knife_obsidian.mdl
- models/rnk/knives/obsidian/w_knife_obsidian.mdl

Cada modelo normalmente exige arquivos auxiliares:
- .vvd
- .dx80.vtx
- .dx90.vtx
- .phy
- materiais .vmt/.vtf

Se o arquivo customizado nao existir no servidor, o plugin RNK ignora a skin e mantem o modelo padrao.
